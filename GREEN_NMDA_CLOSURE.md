# Green matrix + NMDA: morphology enters the nonlinearity twice

**Status:** derived mechanism / candidate diagnostic, grounded in cable theory and NMDAR biophysics. Not a novelty claim and not yet an FCI result.  
**Date:** 2026-08-15.

## 0. Why the AMPA-only gate clarified the mathematics

With voltage-independent current input, a passive dendritic tree is described by its Green/impedance operator.

At a set of dendritic sites, in frequency-domain notation,

```text
v(omega) = Z(omega) i(omega)
```

where `Z_ij` says how current injected at site `j` changes voltage at site `i`.

That is established cable theory.

NMDA changes the problem because the synaptic current at a site depends on the **local voltage that the morphology itself produced**.

Schematically,

```text
I_N,i = g_i(t) B(v_i) (E_N - v_i)
```

and therefore

```text
v = Z [i_AMPA + I_N(v) + ...]
```

This is a nonlinear feedback closure around the passive Green operator.

The useful observation is:

> **Morphology is not merely a filter placed before an NMDA nonlinearity. Its transfer matrix determines both how inputs depolarize each nonlinear site and how the current generated by that site is read out elsewhere.**

That is the precise reason the PNAS “common rat synapse” morphology experiment cannot be interpreted as a pure-cable test.

## 1. First-order local closure

Linearize around a current operating state `v*`.

Define `K` as the diagonal/local incremental **inward** current gain of the voltage-dependent synaptic mechanisms:

```text
K_ii = d I_N,i / d v_i | v*
```

Then a small perturbation obeys, schematically,

```text
delta_v = Z [delta_i_ext + K delta_v]
```

so

```text
(I - Z K) delta_v = Z delta_i_ext
```

and therefore

```text
Z_eff = (I - Z K)^(-1) Z
```

under this inward-current sign convention.

If membrane currents are represented with the opposite sign convention, the algebra carries a `+` rather than `-`; do not mix conventions between NEURON/NEAT/Jaxley.

This equation is ordinary feedback/linearization mathematics. It is **not proposed as a new dendritic theorem**.

What is useful for Dig is the candidate object

```text
L = Z K
```

which asks how strongly the passive electrical geometry closes the loop around local voltage-dependent current.

## 2. The rat FCI NMDA mechanism has an explicit regenerative slope

The released FCI NMODL mechanism uses the Jahr-Stevens-style magnesium gate

```text
B(v) = 1 / [1 + c exp(-gamma v)]
```

with rat `gamma = 0.062 /mV`, `Mg = 1 mM`, and `c = Mg/3.57`.

For the inward-positive convention

```text
I_N(v) = g_N B(v) (E_N - v)
```

we have

```text
B'(v) = gamma B(v) [1 - B(v)]
```

and hence

```text
k_N(v)
 = dI_N/dv
 = g_N B(v) { gamma [1-B(v)] (E_N-v) - 1 }.
```

At sufficiently hyperpolarized/intermediate voltages the bracket can be positive: a little depolarization relieves Mg block, which increases inward NMDA current, which creates further depolarization.

At more depolarized voltages the diminishing driving force eventually reverses that incremental slope.

So even before an all-or-none NMDA plateau is invoked, the model contains a **state-dependent local feedback gain**.

## 3. A dimensionless local loop-gain diagnostic falls out

At DC, if

```text
Z_ii is in MOhm
k_i is in microSiemens
```

then

```text
ell_i = Z_ii * k_i
```

is dimensionless.

Interpret cautiously:

```text
small ell_i     weak local regenerative feedback
larger ell_i    stronger local amplification
ell_i ~ 1       linearized feedback denominator becomes small
```

`ell_i ~ 1` is **not automatically an NMDA-spike threshold**. The full system is dynamic, multi-site, nonlinear and saturating; synaptic conductance itself evolves in time. It is only a local susceptibility diagnostic.

The full multi-site object is the spectral structure of

```text
L = Z K.
```

A large leading eigenvalue means a combination of locations is strongly coupled through the voltage-dependent feedback loop. Again, this is a linearized warning light, not a bifurcation proof unless the full dynamical system is analyzed.

## 4. The source -> nonlinear site -> receiver pathway has TWO Green legs

For an external perturbation at source `j`, the zeroth-order passive voltage at nonlinear site `i` is

```text
delta v_i^(0) = Z_ij delta i_j.
```

That voltage recruits an incremental NMDA current approximately

```text
delta I_N,i ~= k_i Z_ij delta i_j.
```

The resulting extra voltage at receiver `r` is

```text
delta v_r^(1)
 ~= Z_ri k_i Z_ij delta i_j.
```

So the first feedback correction through site `i` contains

```text
C[r, i <- j] = Z_ri * k_i * Z_ij.
```

This is the key structural fact:

```text
source j
  --Z_ij--> local nonlinear site i
  --k_i-->  extra local current
  --Z_ri--> receiver r
```

Morphology enters once on the way **into** the nonlinearity and again on the way **out**.

That is a more mechanistic candidate for the Aizenbud morphology × NMDA effect than a global eigenvalue entropy.

## 5. Pairwise combinatorial interaction adds another useful term

Expand the local NMDA current to second order around the operating state:

```text
I_N,i(v_i)
 ~= I_i*
  + k_i delta v_i
  + 1/2 q_i (delta v_i)^2
```

where

```text
q_i = d^2 I_N,i / d v_i^2 | v*.
```

If two sources `j` and `k` are active together, the cross term in `(delta v_i)^2` contains

```text
Z_ij delta i_j * Z_ik delta i_k.
```

Its contribution at receiver `r` is therefore proportional to

```text
P[r; i | j,k]
    ~ Z_ri * q_i * Z_ij * Z_ik.
```

This is a candidate **pairwise nonlinear susceptibility**.

It says that two sources cooperate strongly at site `i` when:

1. both couple effectively into that site;
2. the current-voltage curve is strongly curved there;
3. that site's generated current can still influence the receiver.

This is exactly the kind of quantity that ordinary branch count cannot see.

Do not call it a new metric yet. It is a perturbative diagnostic derived from standard cable + nonlinear conductance equations.

## 6. Respectable prior art points in the same direction

Several published results make the mechanism biologically plausible rather than merely algebraic.

### Green/impedance theory

Wybo and colleagues have long represented dendritic interactions by Green/impedance kernels, and the current NEAT toolkit explicitly uses impedance matrices to understand how synaptic inputs interact and how dendrites form effective functional compartments.

### Morphology can change NMDAR recruitment through impedance

In CA1 PV interneurons, Cornford et al. (eLife 2019/2020) found that high-impedance dendrites facilitated depolarization and cooperative NMDAR recruitment. Their detailed morphology model showed that morphology itself accounted for part of the difference in supralinear integration between dendritic regions; differences in NMDAR expression accounted for an additional part.

That is almost the qualitative version of the split proposed here:

```text
passive electrical geometry
       x
voltage-dependent synapse
       ->
nonlinear integration
```

### Do not use the tempting withdrawn preprint

A 2024 arXiv manuscript titled *Geometrical determinant of nonlinear synaptic integration in human cortical pyramidal neurons* initially looked almost tailor-made for this Dig. Current public records state that the manuscript was **withdrawn over data-ownership concerns and the authors do not wish it cited**.

Therefore it is deliberately not used as evidence here.

That is exactly why this repository should keep doing literature archaeology before adopting a pleasing result.

## 7. A very small preregisterable descriptor set for Delta_NMDA

If the AMPA-only gate is run, define

```text
Delta_NMDA = FCI_RAT_NMDA - FCI_AMPA
```

as the within-morphology intervention contrast.

Before viewing `Delta_NMDA`, compute only a tiny set of passive + biophysical descriptors.

Candidate set:

```text
1. median / upper-quantile local input impedance Z_ii
2. receiver-weighted loop susceptibility
       sum_i |Z_soma,i * k_i * Z_i,i|
3. leading singular/eigenvalue magnitude of Z K
4. distribution of pairwise source -> site -> soma terms
       |Z_soma,i * k_i * Z_i,j|
```

Use a frozen operating voltage / conductance state or a very small preregistered set of states. Do not optimize the voltage separately for each morphology to maximize correlation.

Compare these against:

```text
area
longest path / bifurcation allocation
electrotonic distance
ordinary DC input/transfer-resistance summaries
```

With only 16 resolved cells, feature count must remain tiny and validation strict.

## 8. Better still: predict a directly simulated intermediate before FCI

FCI is expensive and architecture-dependent.

Before touching it, test whether the passive operator predicts the **actual NMDA intervention** in the detailed neuron.

For frozen matched local stimulus patterns, measure

```text
DeltaV_local
DeltaV_soma
supralinearity ratio
NMDA plateau probability / duration
pairwise interaction residual
```

between NMDA-off and NMDA-on conditions.

Then ask whether `Z K` / the two-Green-leg susceptibilities predict those quantities.

This is a much cleaner mechanistic gate:

```text
passive cable measurement
        ->
predict nonlinear response change
```

Only if that works should we ask whether the same mechanism explains FCI.

## 9. Connection back to “state bends geometry,” now without metaphor

The passive transfer matrix is

```text
Z.
```

Around an operating state with local voltage-dependent gains `K_x`, the linearized effective transfer is

```text
Z_eff(x) = [I - Z K_x]^-1 Z.
```

So the **same anatomy** has a different small-signal influence map at different states because `K_x` changes with local voltage, channel state and synaptic activation.

This is a precise engineering statement:

> state changes incremental coupling on fixed morphology.

There is no need to call it spacetime, a Clockfield or a new geometry.

If we later define receiver-relative distances from `Z_eff` or its time-domain kernels, that is a measurement choice built on established systems theory.

and

## Current Dig sentence

> **A voltage-dependent synapse closes a feedback loop around the dendritic Green operator. Morphology therefore shapes nonlinear computation twice: by determining the voltage that recruits a local nonlinearity and by determining how the resulting current reaches the receiver. The first thing to test is whether that passive loop structure predicts the actual NMDA intervention before asking it to explain FCI.**
